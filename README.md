# Arkanoid (MonoGame)

Simple Arkanoid-style game written in C# using MonoGame.

## What’s inside

* Basic paddle/ball gameplay
* Brick system with different durability
* Simple collision system
* Bonus mechanics
* Level loading from text files
* Basic screen system (menu, game, settings)

## Purpose

This project was built as a practice exercise to explore:

* game loop
* collision handling
* simple game architecture

## Notes

* This is a learning project
* Some systems are simplified
* Includes basic fallback handling for level loading
